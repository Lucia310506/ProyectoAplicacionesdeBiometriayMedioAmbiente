1. En Plesk, el directorio raíz del dominio ldiamur.upv.edu.es debe ser esta carpeta src.

2. Crea la base de datos en Plesk y ejecuta bbdd/Estructura.sql (y bbdd/datos.sql si quieres ejemplos).
   Si la tabla ya existía con columnas Id, Tipo, Valor, Fecha, ejecuta también bbdd/normalizar_columnas.sql.

3. Copia src/BBDD/ConfiguracionProduccion.ejemplo.php a src/BBDD/ConfiguracionProduccion.php
   y escribe host, nombre de la base, usuario y contraseña reales de Plesk.
   ConfiguracionProduccion.php no se sube al repositorio.

4. En un navegador:
   https://ldiamur.upv.edu.es/
   https://ldiamur.upv.edu.es/ux/Aplicacion.html
   https://ldiamur.upv.edu.es/rest/mediciones.php   (GET debe devolver JSON)

5. La app Android envía POST a:
   https://ldiamur.upv.edu.es/rest/mediciones.php

XAMPP local:
- Document root o alias apuntando a src.
- php src/tests/probar_base_datos.php
- php src/tests/probar_rest.php
- node src/tests/probar_peticionario_rest.js
- node src/tests/probar_ux.js

Estructura de pruebas:
- mysql < bbdd/EstructuraPruebas.sql
- MEDICIONES_ENTORNO=pruebas php src/tests/probar_base_datos.php
