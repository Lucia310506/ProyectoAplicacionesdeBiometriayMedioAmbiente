Esta carpeta reúne el sketch y las cabeceras del firmware descrito en `doc/arduino_design.md`, incluida `test.h`. La copia ejecutable para Arduino IDE se conserva en `HolaMundoIBeacon/`. Al enviar `t` por el monitor serie a 115200 baudios, `loop()` emite un beacon `PRUEBA` durante tres segundos y muestra por Serial si se inició y detuvo correctamente.
